# Leetcode Patterns

Pattern recognition is more important than memorizing solutions. These 3 patterns cover a huge percentage of medium-difficulty problems.

---

## The Patterns

| Pattern | When to Use |
|---------|-------------|
| Sliding Window | Subarray/substring problems with a size constraint |
| Two Pointers | Sorted arrays, palindromes, pair finding |
| BFS / DFS | Trees, graphs, shortest path, connected components |

---

## Recognizing Which to Use

**Sliding Window** — keywords: "subarray", "substring", "contiguous", "maximum/minimum of window"

**Two Pointers** — keywords: sorted array, "pair that sums to", "palindrome", remove duplicates in-place

**BFS** — keywords: shortest path, level-by-level, "minimum steps"

**DFS** — keywords: "all paths", "exists a path", "connected components", backtracking
