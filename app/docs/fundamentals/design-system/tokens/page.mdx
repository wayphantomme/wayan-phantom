# Design Tokens

The single source of truth for all visual values. Define once, use everywhere.

---

## CSS Custom Properties

```css
:root {
  /* Colors */
  --color-bg:           #ffffff;
  --color-fg:           #111111;
  --color-fg-muted:     #64748b;
  --color-fg-subtle:    #94a3b8;
  --color-surface:      #f8fafc;
  --color-surface-2:    #f1f5f9;
  --color-border:       #e2e8f0;

  /* Brand */
  --color-accent:       #3b82f6;
  --color-accent-hover: #2563eb;
  --color-success:      #10b981;
  --color-warning:      #f59e0b;
  --color-danger:       #ef4444;

  /* Spacing (4px base) */
  --space-1:  0.25rem;   /* 4px */
  --space-2:  0.5rem;    /* 8px */
  --space-3:  0.75rem;   /* 12px */
  --space-4:  1rem;      /* 16px */
  --space-6:  1.5rem;    /* 24px */
  --space-8:  2rem;      /* 32px */
  --space-12: 3rem;      /* 48px */
  --space-16: 4rem;      /* 64px */

  /* Border radius */
  --radius-sm:   0.375rem;  /* 6px */
  --radius-md:   0.5rem;    /* 8px */
  --radius-lg:   0.75rem;   /* 12px */
  --radius-xl:   1rem;      /* 16px */
  --radius-2xl:  1.5rem;    /* 24px */
  --radius-full: 9999px;

  /* Shadows */
  --shadow-sm:  0 1px 2px rgba(0,0,0,0.05);
  --shadow-md:  0 4px 6px -1px rgba(0,0,0,0.1), 0 2px 4px -1px rgba(0,0,0,0.06);
  --shadow-lg:  0 10px 15px -3px rgba(0,0,0,0.1), 0 4px 6px -2px rgba(0,0,0,0.05);
  --shadow-xl:  0 20px 25px -5px rgba(0,0,0,0.1), 0 10px 10px -5px rgba(0,0,0,0.04);

  /* Z-index */
  --z-base:    0;
  --z-above:   10;
  --z-modal:   100;
  --z-toast:   200;
  --z-tooltip: 300;
}
```

## Tailwind v4 Tokens

In Tailwind v4, tokens are CSS custom properties. No `tailwind.config.js` needed.

```css
@import "tailwindcss";

@theme {
  --color-brand:      #3b82f6;
  --color-brand-dark: #1d4ed8;
  --spacing-18:       4.5rem;
  --radius-card:      1.75rem;
}
```

```tsx
// Use in JSX
<div className="bg-brand text-white rounded-card p-6">
  Hello
</div>
```

## Semantic Color Naming

Avoid naming tokens after their visual property. Name them by their semantic role.

```
Bad:   --color-blue-500
Good:  --color-accent

Bad:   --color-gray-100
Good:  --color-surface
```

This way, if you switch from blue to purple as your accent color, one token change updates everything.

## Dark Mode with Tokens

```css
:root {
  --color-bg:  #ffffff;
  --color-fg:  #111111;
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-bg:  #0f172a;
    --color-fg:  #f1f5f9;
  }
}
```

All components using `var(--color-bg)` automatically switch. No component changes needed.
