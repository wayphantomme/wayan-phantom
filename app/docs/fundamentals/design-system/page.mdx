# Design System

A design system is a shared language between designers and developers. Tokens define the values. Typography defines the scale. Components consume both.

---

## Why Design Systems Matter

Without a design system, every developer makes slightly different spacing, color, and typography decisions. The result: inconsistent UI that's expensive to maintain.

With a design system: one change to a token updates every component that uses it.

---

## The Three Layers

```
Design Tokens         → raw values (colors, spacing, font sizes)
     ↓
Typography & Scale    → how tokens map to text styles
     ↓
Components            → Button, Card, Input consume tokens
```
